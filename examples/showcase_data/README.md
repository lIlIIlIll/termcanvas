# 内存数据浏览器

离线示例：左侧是虚拟文件树，右侧是选中数据集的表格。示例数据、文件夹和表格编辑仅存在于内存，退出即重置；程序不读取或写入真实文件。

在仓库根目录运行：

```sh
cd examples/showcase_data
cjpm run
```

- `Tab` 切换文件树和表格焦点，方向键选择，`Enter` 查看表格行详情。
- `/` 输入过滤条件，`s` 切换名称排序方向，`e` 编辑选中行的 `NAME *` 列。
- 文件树聚焦时：`f` 创建文件，`n` 创建文件夹，`r` 重命名，`d` 删除选中项及其所有子项。对文件执行创建时，新条目位于其父文件夹内；工作区根目录不能删除或重命名。
- 输入时按 `Enter` 应用、`Esc` 取消；其他时候按 `q` 或 `Ctrl+C` 退出。过滤区分大小写，空过滤条件显示所有行。

新建文件不含表格行。所有名称和修改均为模拟内容，不影响本地文件系统。
